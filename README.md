# IT Study Planner

Простой планировщик учебных задач на чистых HTML, CSS и JavaScript.

## Возможности

- добавление задач с категорией (HTML, CSS, JavaScript, Другое)
- отметка выполнения и удаление задач
- статистика и индикатор прогресса
- фильтры: все / активные / выполненные
- очистка списка с подтверждением
- сохранение задач в localStorage
- адаптивная вёрстка для смартфонов

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не нужны.
