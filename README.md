# IT Study Planner
Учебное веб-приложение для планирования задач.
## Технологии
- HTML5
- CSS3
- JavaScript
## Возможности
- Добавление задач
- Удаление задач
- Отметка выполнения
- Фильтрация
- Сохранение данных в браузере
## Автор
Студент IT-специальности колледжа.
Не указывайте личные контакты и другие персональные данные.
Этап 3. Загрузка файлов через GitHub — 15 минут
Для студентов, которые впервые работают с Git, используем загрузку через браузер.
1. Откройте созданный репозиторий.
2. Нажмите Add file.
3. Выберите Upload files.
4. Перетащите файлы проекта.
5. Убедитесь, что index.html, style.css и script.js находятся в корне репозитория.
6. В поле Commit changes введите:
Added IT Study Planner files
7. Нажмите Commit changes.
